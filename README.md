# Profundis

Search internet infrastructure and trace connections between domains.

- Search hosts, DNS records, TLS certificates and WHOIS.
- [Enumerate and export subdomains](https://profundis.io/tools/subdomains) (up to 300 per lookup on the Free plan, using monthly credits).
- Explore shared IPs, certificates, tracking IDs and registrants in [Pivot](https://profundis.io/pivot).
- Find websites using [visually similar favicons](https://profundis.io/tools/favicons).

Use the [web app](https://profundis.io), query the [API](https://docs.profundis.io/api/api-usage/), or connect an assistant through [MCP](https://docs.profundis.io/mcp/connect/).

We write about our investigations and how we build the tools:

- [Following a spam email to 208 domains](https://blog.profundis.io/blog/from-one-spam-email-to-208-domains/)
- [How our favicon similarity search works](https://blog.profundis.io/blog/favicon-similarity-search/)
